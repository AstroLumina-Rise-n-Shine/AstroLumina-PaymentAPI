# AstroLumina-PaymentAPI

Stateless Revolut Pay Merchant API for AstroLumina. The frontend sends amount + currency from the catalog; this API calls POST /create-order and returns a payment token for the Revolut Pay widget. See the [project Wiki](https://github.com/AstroLumina-Rise-n-Shine/AstroLumina-PaymentAPI/wiki) for:

- [Security](https://github.com/AstroLumina-Rise-n-Shine/AstroLumina-PaymentAPI/wiki/Security)
- [Deployment](https://github.com/AstroLumina-Rise-n-Shine/AstroLumina-PaymentAPI/wiki/Deployment)
